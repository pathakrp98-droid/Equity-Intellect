# Free-hosting foundation implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make AlphaDesk build reproducibly on Windows, block all paid AI traffic by default, expose that state honestly, and run the API and frontend as one free-hosting-ready service.

**Architecture:** A single backend policy guards every OpenAI call and the research worker. A small public capabilities route lets React explain the disabled state without exposing secrets. Express serves only the compiled frontend after all API routes, and repository configuration describes a Render Free service without creating one.

**Tech Stack:** Node.js 24, TypeScript 5.9, pnpm 11, Node test runner, Express 5, React 19, TanStack Query, Vite 7, PostgreSQL/Drizzle.

**Spec:** `docs/superpowers/specs/2026-08-28-free-hosting-migration-design.md`

## Global constraints

- No payment, Replit Agent, external AI call, hosting account mutation, OAuth credential creation, or private-data upload.
- Keep `AI_REQUESTS_ENABLED` false by default and require the exact string `true` plus a key before reporting a provider available.
- Do not remove saved research, Copilot history, Guardian, Morning Brief, manual ETF prices, CSV import, or Replit compatibility.
- Do not add cash features or transaction-history requirements.
- Preserve Node 24, pinned dependencies, `minimumReleaseAge: 1440`, and the reviewed SQL migration path.
- Use failing behavior tests before production-code changes. A failing production build is the regression test for platform-only package configuration.
- Do not push until relevant tests, typecheck, and the production build all pass.

- [x] **Step 3: Implement the minimal policy**

```ts
export function aiRequestsEnabled(environment = process.env): boolean {
  return environment.AI_REQUESTS_ENABLED === "true";
}

export function openAiAvailable(environment = process.env): boolean {
  return aiRequestsEnabled(environment) && Boolean(environment.OPENAI_API_KEY?.trim());
}

export function assertOpenAiAvailable(environment = process.env): void {
  if (!aiRequestsEnabled(environment)) throw new Error("Paid AI requests are disabled.");
  if (!environment.OPENAI_API_KEY?.trim()) throw new Error("OPENAI_API_KEY is not configured");
}
```
